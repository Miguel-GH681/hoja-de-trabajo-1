# Hoja de trabajo 3

Esta tarea consiste en utilizar javascript en nuestra página web con el fin de darle un comportamiento dinámico. En los diferentes scripts se utiliza el objeto global que es el "document" para obtener elementos html y poder manipularlos con javascript, así como la creación de elementos html desde javascript e insertarlos en nuestra página. Con esta tarea se tiene el objetivo de poner en práctica los nuestro conocimientos sobre javascript y las distintas maneras de manipular elementos HTML.
